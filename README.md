# My Personal Portfolio Website 🚀

Welcome to the repository for my personal portfolio website! This is **my very first web development project**, built entirely from scratch to showcase my journey, skills, and future projects as an aspiring developer.

## 📌 Project Overview
This project is a fully responsive, single-page portfolio website. The goal of this project was to apply everything I have learned about basic web structures, layout styling, and interactive scripting into a real-world application. 

### Key Features:
*   **Responsive Design:** Optimized for a seamless experience across mobile phones, tablets, and desktop screens.
*   **Navigation Menu:** A smooth-scrolling header menu featuring a mobile hamburger menu toggle.
*   **About Me Section:** A space introducing who I am, my education background, and core focus.
*   **Skills Section:** A visually structured display showcasing the technologies I am currently learning and using.
*   **Contact us:** A functional or styled enabling visitors to reach out to me directly.

---

## 🛠️ Built With
This project uses clean, semantic code without external heavy frameworks to establish a strong foundational understanding of the web core:

*   **HTML5:** Structured the content layout and semantic elements.
*   **CSS3:** Styled the page, built layouts using Flexbox/Grid, and handled media queries for responsiveness.
*   **JavaScript (Vanilla):** Implemented logic for the mobile navigation toggle, smooth scroll interactions, and tab controls.

---

## 📁 Project Structure
To keep the codebase neat and scalable, the project is organized into the following file hierarchy:

```text
├── assets/
│   ├── images/          # Profile picture, project screenshots
│   └── icons/           # Social media and technical skill icons
├── index.html           # Main HTML structure of the portfolio
├── style.css            # Custom layout rules, animations, and typography
└── script.js            # JavaScript functionality and event listeners
```

## 🚀 How to Run the Project Locally
If you want to view this project locally on your machine, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd your-repository-name
    ```
3.  **Open the site:**
    *   Simply double-click the `index.html` file to launch it instantly in any default web browser.
    *   *Alternative:* If using VS Code, right-click `index.html` and select **"Open with Live Server"** to view real-time changes.
